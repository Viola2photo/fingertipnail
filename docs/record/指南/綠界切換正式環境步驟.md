# 綠界切換成正式環境（真的收錢）

> **安全原則：HashKey、HashIV 只在你自己的電腦上輸入，不要貼進任何聊天（包括 Claude）、LINE、Email 或截圖。**
> 特店編號（MerchantID）不算機密，但也不需要傳給我。我只需要看你最後的「系統設定檢查」截圖，那個畫面只顯示 ✓／✕，不會顯示金鑰。

建議時間：新款上架完、你手邊有 30 分鐘、而且當天可以去超商測試寄件的時候。

## 第 1 步：在綠界後台拿到正式資料
1. 登入綠界廠商後台 https://vendor.ecpay.com.tw （用正式帳號，不是測試帳號）
2. 左邊「系統開發管理」→「系統介接設定」
3. 你會看到：**特店編號（MerchantID）、HashKey、HashIV**
4. 檢查「物流」是否有自己的一組 HashKey／HashIV（有些帳號金流、物流共用同一組；如果物流頁面另外顯示一組，就用物流那組）
5. 確認已開通：**超商 C2C 店到店（7-11、全家）**、**超商取貨付款（代收貨款）**、信用卡收款
6. 舊倉庫曾經公開過金鑰；如果你的正式帳號在那之前就存在，請聯絡綠界客服（02-2655-1775）重新產生 HashKey／HashIV，再用新的

先不要關掉這個頁面。

## 第 2 步：把金鑰存進 Firebase（不會出現在網站或 GitHub）
用「檔案」的方式存，可以避免上次 LINE 金鑰那種「貼錯一個字」的問題。

1. 開「記事本」，**只貼上 HashKey**（前後不要有空格或空行），存成 `C:\Users\viola\k.txt`
2. 開 cmd，輸入：
   ```
   cd fingertipnail
   firebase functions:secrets:set ECPAY_HASH_KEY --data-file C:\Users\viola\k.txt
   ```
3. 回到記事本，把內容換成 **HashIV**，存檔，輸入：
   ```
   firebase functions:secrets:set ECPAY_HASH_IV --data-file C:\Users\viola\k.txt
   ```
4. 物流的兩把（如果物流和金流共用一組，就再填一次一樣的）：
   ```
   firebase functions:secrets:set ECPAY_LOGISTICS_HASH_KEY --data-file C:\Users\viola\k.txt   ← 檔案裡放物流 HashKey
   firebase functions:secrets:set ECPAY_LOGISTICS_HASH_IV --data-file C:\Users\viola\k.txt    ← 檔案裡放物流 HashIV
   ```
5. **全部做完後刪掉 k.txt，並清空資源回收筒。**
6. 如果它問「要不要重新部署使用這個密鑰的函式」，回答 N（第 4 步會一起部署）。
7. 電子發票目前沒開，`ECPAY_INVOICE_*` 不用動。

## 第 3 步：改一般設定
1. 用記事本打開 `C:\Users\viola\fingertipnail\functions\.env.nailproject-40022`
2. 改成（或新增）這幾行：
   ```
   ECPAY_ENV=production
   ECPAY_MERCHANT_ID=你的特店編號
   ECPAY_LOGISTICS_MERCHANT_ID=-
   SITE_URL=https://tiptipart.com
   ```
   （物流特店編號跟金流不同時，才把 `-` 換成物流的編號）
3. 存檔

## 第 4 步：部署
```
cd fingertipnail
firebase deploy --only functions:api,functions:maintenance
```
看到 `Deploy complete!` 就成功。**不要用含 hosting 的部署**，會把網站蓋回舊版。

## 第 5 步：檢查
1. 打開 https://tiptipart.com/admin.html → 「系統設定檢查」→「查看設定」
2. 環境要顯示「正式」，而且沒有紅色 ✕ → 截圖給我（這個畫面不會顯示金鑰）
3. 後台「出貨設定」確認寄件人姓名、手機是你本人的

## 第 6 步：真實小額測試（一定要做）
1. 請朋友（或用你的另一個帳號）在網站買 1 件，選「超商取貨付款」，門市選你家附近
2. 後台產生物流單 → 拿去超商寄 → 自己去取貨付款
3. 確認：訂單狀態有變「已出貨／已完成」、庫存有扣、綠界後台看得到這筆代收款
4. 再用信用卡買 1 件最便宜的，確認變「已付款」後，到綠界後台退刷
5. 都沒問題，就可以開始對外宣傳

## 出問題時
- 部署失敗：把 cmd 最後 20 行截圖給我（那裡不會有金鑰）
- 想退回測試環境：把 `ECPAY_ENV` 改回 `stage` 再部署一次即可
