# 訂單通知信設定步驟

設好之後，網站會自動寄三種信，寄件人是 **指尖造藝 <hello@tiptipart.com>**：

| 信 | 誰會收到 | 什麼時候寄 |
|----|---------|-----------|
| 新訂單通知 | 你（店家） | 客人信用卡付款成功，或選超商取貨付款下單時 |
| 訂單成立 | 客人 | 同上 |
| 出貨通知 | 客人 | 你在後台按「建立綠界超商物流單」或「標記已出貨」時 |

客人如果直接回覆通知信，會寄到 hello@tiptipart.com，再轉到你的 Gmail。

**費用**：Resend 免費方案每月 3,000 封、每天 100 封，目前用不完。Google 這邊多一個密鑰，大約每月 US$0.06。

---

## 第 1 步：申請 Resend（約 5 分鐘）

1. 打開 https://resend.com ，按 **Get Started**，用你的 Gmail 註冊或用 Google 登入。
2. 左邊選 **Domains** → **Add Domain**。
   - Name 填 `tiptipart.com`
   - Region 選 **Tokyo (ap-northeast-1)**（離台灣最近）
   - 按 **Add**。
3. 畫面會列出 3～4 筆 DNS 記錄（MX、TXT）。
   - 如果有 **Auto configure／Sign in to Cloudflare** 之類的按鈕，按它並登入 Cloudflare 同意即可，跳到第 5 點。
   - 沒有的話照第 4 點手動加。
4. 另開 Cloudflare → `tiptipart.com` → **DNS** → **Records**，把 Resend 畫面上的每一筆照抄新增：
   - Type、Name、Content（或 Value）、Priority 都照 Resend 畫面複製貼上。
   - Name 只要填 Resend 寫的前面那段（例如 `send`、`resend._domainkey`），Cloudflare 會自動接上 `.tiptipart.com`。
   - **不要刪除或修改原本的 MX 記錄**（那是收信用的 Email Routing）。Resend 的記錄名稱是 `send` 開頭，不會互相影響。
5. 回 Resend 按 **Verify DNS Records**。通常幾分鐘內變成綠色 **Verified**（最久可能要等一小時）。
6. 左邊選 **API Keys** → **Create API Key**：
   - Name：`fingertipnail`
   - Permission：**Sending access**
   - Domain：`tiptipart.com`
   - 按 **Add**，複製 `re_` 開頭的那串（只會顯示一次，先貼到記事本）。

## 第 2 步：把金鑰和你的信箱放進網站設定

在 `C:\Users\viola\fingertipnail` 開命令提示字元：

```
firebase functions:secrets:set RESEND_API_KEY
```

出現提示時貼上剛剛的 `re_...`，按 Enter（畫面不會顯示貼上的內容，正常）。

再用記事本打開 `functions\.env.nailproject-40022`，在最後加一行（換成你想收新訂單通知的信箱）：

```
SHOP_NOTIFY_EMAIL=你的Gmail@gmail.com
```

存檔。

## 第 3 步：更新程式並部署

1. 這次的修改合併後，到 GitHub 下載最新 ZIP，**覆蓋**到 `C:\Users\viola\fingertipnail`（不要刪整個資料夾，`.env.nailproject-40022` 要留著）。
2. 執行：

```
firebase deploy --only functions:api,functions:maintenance
```

如果部署時問 `MAIL_FROM`，直接按 Enter 用預設值 `指尖造藝 <hello@tiptipart.com>`。

> 如果部署失敗、訊息提到 `RESEND_API_KEY` 和 permission：到 Google Cloud Console → Secret Manager → `RESEND_API_KEY` → 權限 → 新增主體 `1004628981925-compute@developer.gserviceaccount.com`，角色選「Secret Manager Secret Accessor」，存檔後再跑一次部署指令。

## 第 4 步：確認

1. 後台總覽按「查看設定」，「通知信」兩項都要是綠色。
2. 打開下午那筆測試訂單，右邊「通知信」區塊按 **補寄通知信**，你和那筆訂單填的 Email 都會收到信。
   - 那筆訂單如果當時沒填 Email，就只會寄給你。
3. 之後新訂單會自動寄。每筆訂單詳情都看得到哪封信什麼時候寄出；寄失敗時會顯示原因，系統每 10 分鐘自動重寄。

## 小提醒

- 結帳頁的 Email 已改成必填，客人才收得到通知。
- 第一次寄到客人的 Gmail 可能被歸到「促銷內容」或垃圾郵件，請客人把 hello@tiptipart.com 加入聯絡人。
