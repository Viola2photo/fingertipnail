# 2026-11-26 第 2 天：把蝦皮上架檔做成「一次上傳」

## 今天做的事
- 店主從蝦皮賣家中心下載了官方「大量上傳」基礎範本。Claude 照範本的欄位，把 131 款有庫存的穿戴甲填進去，分成兩批：第 1 批 39 款（庫存 2 件以上，或聖誕／新年款），第 2 批 92 款。
- 規格用「尺寸」，只列有庫存的尺寸，各尺寸分開填庫存；貨號沿用網站編號，之後對帳和盤點比較方便。
- 圖片不用一張張上傳：範本可以直接填網址，所以用網站上現有的商品照片網址（800×800，每張都小於 2MB）。
- 物流照店主的設定，只開 7-11 和全家。

## 踩到的坑
- 蝦皮的範本檔，一般的 Python Excel 套件（openpyxl）打不開（工作表的 XML 有一個值不合規格）。改成直接修改 xlsx 裡的 XML，只在「上傳模板」這一頁加資料列，其他頁原封不動，避免蝦皮認不得。完成後用 LibreOffice 開啟檢查，欄位都對。
- 查到蝦皮禁止「引導站外交易」，所以商品描述拿掉官網網址，原本計畫的「蝦皮包裹放官網小卡」也取消。
- 果凍膠加購品的大小碼和庫存欄位對不起來，先不放進批量檔，之後手動上架。
